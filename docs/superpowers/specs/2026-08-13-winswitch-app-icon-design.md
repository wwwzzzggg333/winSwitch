# winSwitch 应用图标设计

## 目标

为 winSwitch 设计一枚现代、简洁、易于识别的正式应用图标，替换当前 Qt 系统默认电脑图标。图标需要直观表达“在多个窗口之间快速切换”，并在 Windows 任务栏、系统托盘、窗口标题栏和文件资源管理器中保持清晰。

## 视觉概念

图标采用“环形切换”构图：两个圆角窗口前后错位叠放，右下区域以连续箭头表达窗口焦点的循环切换。整体不使用方形或圆形底板，以独立图形呈现，保持轻盈并减少视觉占用。

图形应满足以下要求：

- 两个窗口具有明确的前后层次，但轮廓保持简洁。
- 切换箭头与窗口轮廓自然衔接，不能像额外贴上的装饰符号。
- 不加入字母、文字、标题栏按钮或细小窗口内容。
- 四周保留足够透明留白，避免在任务栏和文件缩略图中贴边。
- 主轮廓在 16 px 和 24 px 下仍可辨认为“叠放窗口与切换”。

## 色彩与质感

- 主色从亮蓝过渡至紫色，渐变方向大致为左上至右下。
- 使用轻微高光和克制的立体层次，使前后窗口容易区分。
- 不使用实体底板、投射阴影、发光光晕或复杂纹理。
- 不依赖极细描边表现结构，避免缩小时丢失细节。
- 透明背景，图形边缘需要干净、无明显彩边。

## 尺寸适配

主源图以透明高分辨率正方形 PNG 保存。交付时生成：

- 1024 × 1024 PNG：高分辨率主源图。
- 256 × 256 PNG：常规资源与文档展示。
- Windows ICO：至少包含 16、24、32、48、64、128 和 256 px 图层。

16–32 px 小尺寸版本允许进行必要的像素级简化，包括加粗主轮廓、扩大图形间隙和减少高光细节，但不得改变核心构图。

## 程序接入

- 将最终 PNG 与 ICO 放入项目的 `resources/icons/` 目录。
- 通过 Qt 资源文件提供运行时图标，替换 `QStyle::SP_ComputerIcon`。
- 应用图标用于主窗口、设置窗口、消息框所属应用和系统托盘。
- Windows 可执行文件通过 CMake 引用 `.rc` 资源，使文件资源管理器和任务栏显示同一枚图标。
- 其他平台继续从 Qt 应用图标读取 PNG，不额外引入平台专属品牌变体。

## 验收标准

- 图标为透明背景，不包含底板、文字或水印。
- 用户可一眼识别出叠放窗口与循环切换的含义。
- 蓝紫渐变和轻微立体高光与确认的设计方向一致。
- 在 16、24、32、48 和 256 px 预览中轮廓清楚，无糊边或元素粘连。
- Windows 可执行文件、任务栏、窗口标题栏和系统托盘均显示新图标。
- Release 构建和现有自动化测试保持通过。

## 范围边界

本次仅设计并接入应用品牌图标，不重做界面内的功能图标，不新增启动画面、品牌文字或安装程序视觉资产。
