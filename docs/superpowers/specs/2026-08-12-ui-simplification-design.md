# winSwitch 界面精简设计

## 目标

精简主面板和配置界面，完整移除当前不再需要的置顶功能，并修正窗口卡片关闭图标的垂直对齐。

## 功能范围

### 1. 移除置顶功能

- 主面板不再显示“置顶/已置顶”按钮。
- 配置界面不再显示“置顶应用”编辑区域。
- 删除置顶动作、控制器处理、配置字段及分组排序逻辑。
- 读取旧配置时忽略遗留的 `pinned` 字段；以后保存的配置不再写入该字段。
- 已有置顶数据不再影响应用分组顺序。

### 2. 修正关闭图标

- 窗口卡片关闭按钮不再使用受字体基线影响的文本 `×`。
- 使用固定尺寸、居中绘制的关闭图标，保持现有按钮大小、颜色和悬停反馈。

### 3. 精简配置界面

- 删除诊断页及相关平台能力展示代码。
- 删除导入配置、导出配置按钮及相关界面处理代码。
- 删除顶部“设置”标题。
- 由于只保留常规设置，取消标签页容器，直接显示热键、缩略图、MRU、语言、排除应用和保存按钮。
- 保留底层配置文件读写能力，不影响程序正常加载和保存配置。

## 兼容性与边界

- 不改变窗口枚举、激活、关闭、搜索、筛选及快捷键行为。
- 不删除日志和平台能力底层实现；只移除配置界面的诊断入口。
- 本轮按用户要求不新增或运行自动化测试，由用户直接进行界面验证。

## 验收标准

- 主面板不存在任何置顶入口，旧置顶配置不再改变排序。
- 卡片关闭图标在圆形按钮内水平、垂直居中。
- 配置界面没有“设置”标题、诊断页、置顶应用和导入/导出按钮。
- 配置保存后仍能正确更新剩余设置项。
