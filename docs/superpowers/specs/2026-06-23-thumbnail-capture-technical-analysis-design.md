# mySwitcher 缩略图抓取技术分析文档设计说明

## 1. 背景

当前项目在 Windows 平台下使用 `PrintWindow` 抓取窗口缩略图，已经出现以下典型现象：

- 只能截到标题栏
- 只能截到顶部一部分
- 截图全黑或全白
- 截图为空
- 某些窗口偶发可截，偶发不可截

从现有实现看，Windows 缩略图抓取逻辑位于：

- `src/platform/windows/WinWindowSource.cpp`

当前核心路径为：

1. 使用 `GetClientRect()` 获取尺寸
2. 使用 `CreateCompatibleBitmap()` 创建位图
3. 调用 `PrintWindow(hwnd, memDc, PW_RENDERFULLCONTENT)` 绘制
4. 使用 `GetDIBits()` 读取像素
5. 对纯黑/纯白结果做空白图过滤
6. 对图像缩放输出

用户当前最关心的问题是：为什么有些窗口只能截到标题栏，或者只能截到一部分。

## 2. 文档目标

本次新增的技术分析文档目标是：

- 解释当前缩略图抓取问题的成因

- 明确当前实现中的具体风险点
- 为后续实现优化提供技术依据

- 后续实现前的技术依据
- 排障说明
- 代码评审和方案评估的参考材料

## 6. 各章节内容深度

### 6.1 背景与问题现象

本节要写清当前实际观察到的问题现象：

- 只截到标题栏
- 只截到顶部一部分
- 截图全黑
- 截图全白
- 截图为空
- 同一种窗口在不同状态下表现不同

本节目标：

- 先统一问题表述
- 用现象描述建立共同上下文
- 不在这里直接展开 API 细节

### 6.2 当前实现路径

本节要严格基于当前代码说明抓图链路：

- `GetClientRect()` 获取尺寸
- `CreateCompatibleBitmap()` 创建承接位图
- `PrintWindow(..., PW_RENDERFULLCONTENT)` 请求绘制
- `GetDIBits()` 读回像素
- 纯黑/纯白过滤
- 最终缩放输出

本节目标：

- 让后续每一个问题都能对应到实现链路上的具体步骤
- 让读者无需先翻源码，也能理解当前实现机制

### 6.3 为什么会只截到标题栏或截不全

这是全文最关键的部分，必须写得最清楚。

本节要分析以下逻辑：

- `GetClientRect()` 获取的是客户区大小，不包含标题栏和边框
- `PrintWindow()` 在很多程序上并不严格等于“只绘制客户区”
- 当绘制输出范围与承接位图尺寸不一致时，会发生裁切
- “只剩顶部一截”是尺寸语义不一致时的典型表现

本节需要明确结论：

- 这类问题首先是当前实现策略存在明显风险
- 同时也叠加了 `PrintWindow` 跨程序行为不一致的问题

### 6.4 为什么有些窗口完全截不到

本节要分析 API 和窗口类型限制，包括：

- Electron / Chromium 窗口
- GPU 硬件加速窗口
- DirectX / OpenGL 窗口
- 最小化窗口
- 被遮挡或后台窗口
- 高权限或受保护窗口
- 某些现代 UI 框架窗口

本节目标：

- 明确并不是所有失败都属于“实现写错”
- 说明一部分问题来源于平台和应用自身的限制

### 6.5 当前实现的具体风险点

本节要把当前实现中的风险整理成清单，至少包括：

- 尺寸来源风险
- `PrintWindow` 成功但内容不完整的风险
- 空白图过滤过于粗糙的风险
- 没有对“半错图”做识别
- 没有对窗口类型做降级策略
- 没有后备抓图路径

本节目标：

- 形成后续改造前的 checklist

### 6.6 可选改进方向

本节只写技术方向，不直接给出实现代码。

建议覆盖：

- 改用整窗尺寸而不是客户区尺寸
- 评估 `GetWindowRect()` 与 `DWMWA_EXTENDED_FRAME_BOUNDS`
- 明确后续到底要截“整窗”还是“客户区”
- 对抓图失败窗口降级为图标 + 标题
- 把问题区分为“可优化问题”和“不可保证问题”

本节目标：

- 给后续实现提供方向
- 避免在分析文档里直接提前承诺具体实现方案

### 6.7 不应误判为普通 bug 的场景

本节要明确说明：

- 某些窗口即使修正当前实现，也仍可能抓不到
- 某些应用类型天然不稳定
- 某些窗口在最小化、被遮挡、后台或高权限状态下会失败

本节目标：

- 帮助后续开发和产品识别“代码问题”和“平台天然限制”的边界

### 6.8 结论

本节要收束成几条明确结论：

- 为什么会只截到标题栏
- 为什么会截不全
- 为什么有些窗口完全抓不到
- 哪些问题值得优先修正
- 哪些问题不应承诺完全解决
