winSwitch 功能介绍 / Features

【中文】
winSwitch 是一款简洁高效的 Windows 窗口切换工具，帮助你快速找到并切换已打开的窗口。

主要功能
• 使用全局快捷键快速呼出或隐藏窗口切换面板
• 按应用程序分组展示图标和窗口缩略图，并支持搜索与筛选
• 支持键盘和鼠标操作，可快速选择并切换到目标窗口
• 支持排除不需要显示的应用，以及关闭单个窗口或同一应用的整组窗口
• 支持系统托盘常驻和开机启动，并可自定义快捷键、语言和缩略图显示

[English]
winSwitch is a lightweight Windows window switcher that helps you quickly find and switch to open windows.

Key features
• Show or hide the window switcher with a global keyboard shortcut
• Group windows by application with icons and thumbnails, plus search and filters
• Navigate and switch windows using the keyboard or mouse
• Exclude unwanted applications, and close one window or an entire application group
• Stay available in the system tray, start automatically when you sign in to Windows, and customize the shortcut, language, and thumbnail display
